# Network Traffic Analysis Using Wireshark

## Overview
A beginner cybersecurity project focused on observing and analysing network traffic using Wireshark.

## Objectives
- Understand basic network communication.
- Analyse DNS queries and responses.
- Inspect TCP packets and connection flags.
- Observe TLS handshake messages and encrypted application traffic.

## Tools Used
- Wireshark
- Npcap
- Windows

## Practical Work
1. Captured traffic using the Wi-Fi network interface.
2. Applied the `dns` display filter to inspect DNS queries and responses.
3. Applied the `tcp` display filter to inspect TCP traffic.
4. Examined packet details, IP addresses, ports, and TCP flags.

## Findings
The capture contained DNS queries and responses, TCP packets, and TLS traffic. This exercise helped me understand how Wireshark can be used to observe normal network communication.

## Learning Outcomes
- Basic packet analysis
- DNS resolution
- TCP communication
- Understanding encrypted network traffic
